# Simulation

This directory contains the CARLA simulation material used to generate the self-driving car scenarios evaluated in the empirical study.

## Structure

```text
simulation/
├── screencasts/
├── scripts/
└── README.md
```

### `scripts/`

Contains the CARLA scripts used to configure and execute the study scenarios.

### `screencasts/`

Contains the recorded scenario videos presented to participants during the survey.

Because CARLA executions may vary across environments and runs, the videos in `screencasts/` should be treated as the reference scenarios for reproducing the participant-facing study material.
