# Analysis

This directory contains two Jupyter notebooks:

- [`analysis.ipynb`](./analysis.ipynb)
- [`process_raw_data.ipynb`](./process_raw_data.ipynb)

## `analysis.ipynb`

This is the main notebook that computes the analyses and results. It uses the processed and anonymized dataset in [`../data/processed/final_processed_data.csv`](../../data/processed/final_processed_data.csv).

## `process_raw_data.ipynb`

This notebook prepares and preprocesses the collected data. Due to confidentiality reasons, we do not publicly share the raw data. However, the [`data/processed`](../../data/processed/) directory contains the processed dataset that can be used for further analysis.
